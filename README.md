# SynaptiQ - Adaptive Learning Platform

SynaptiQ is a web-based adaptive learning platform built for computer science students and instructors. It combines self-paced video instruction, concept quizzes, interactive simulations, and a faculty analytics interface called AURA (Adaptive Unified Resource and Assessment).

## Overview

The platform is split into two primary areas:

1. **Student Learning Interface**: Students select courses (such as Tree and Graph Traversals, or Sorting and Searching), watch instructional modules, practice with interactive simulators, run code in a browser sandbox, and receive hints from an AI tutor.
2. **Faculty Analytics Dashboard (`/faculty/analytics`)**: Instructors can review cohort mastery across courses, track remediation pathways for specific students, compare the yield of different teaching interventions, and inspect automated diagnostic recommendations.

## Main Features

### Student Modules
- **Interactive Course Player (`/learn`)**: Synchronized video lessons, concept quizzes, flashcards, and conceptual knowledge graphs.
- **Code Lab**: An in-browser coding playground supporting Python and JavaScript with direct execution and stdout display.
- **Attention Tracking**: Optional webcam-based gaze and posture checks running client-side with `face-api.js` to nudge students who look away for extended periods.
- **AxonBuddy AI Assistant**: Contextual explanations for code and quiz questions via the OpenRouter API.

### Faculty Analytics (AURA)
- **Course Selection Switcher**: Dynamically loads real data breakdowns for Data Structures (CS204), Algorithms Analysis (CS301), and Object-Oriented Programming (CS202).
- **Competency Diagnostics**: Visual horizontal progress gauges comparing unit scores against a 70% institutional target, highlighting the lowest-scoring topic.
- **Cohort Distribution**: Segmented breakdown of students categorized as Mastered, Developing, or Needing Intervention.
- **Remediation Case Traces**: Step-by-step longitudinal tracking of scaffolded interventions (initial test, visual simulator, re-evaluation, practice lab, final mastery).
- **Intervention Yield Comparison**: Measures percentage-point gains across different instructional methods, from passive code walkthroughs to active problem synthesis.
- **Action Items**: Concrete suggestions generated by the diagnostic engine to help teachers triage lecture time and assign targeted practice.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Authentication**: NextAuth.js
- **Database / Storage**: Supabase
- **Computer Vision**: face-api.js (Tiny Face Detector models loaded from `public/models`)
- **LLM Integration**: OpenRouter API (`@/lib/openrouter.ts`)

## Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/praveen-neshamani/SynaptiQ.git
   cd SynaptiQ
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Download required face detection models:
   ```bash
   npm run setup-models
   ```
   This downloads the weights for `tiny_face_detector` and `face_landmark_68_tiny` into the `public/models/` folder.

### Environment Configuration

Create a `.env.local` file in the project root:

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key

# OpenRouter (AI Tutor)
OPENROUTER_API_KEY=your-openrouter-api-key

# NextAuth
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-random-secret-key-at-least-32-chars

# OAuth Providers (optional for local testing)
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
GITHUB_CLIENT_ID=your-github-client-id
GITHUB_CLIENT_SECRET=your-github-client-secret
```

### Running Locally

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

- Student Interface: `http://localhost:3000/dashboard`
- Faculty Analytics: `http://localhost:3000/faculty/analytics`

## Note on Video Assets

Large lesson video files (`.mp4`) are excluded from this Git repository to stay under GitHub upload limits. If you are developing locally and want full offline video playback, place your video files in the following folders:

- `public/videos/sorting-searching/`
- `public/videos/tree-graph-traversals/`

If these files are absent, the application falls back to online video streams and interactive simulators without crashing.
